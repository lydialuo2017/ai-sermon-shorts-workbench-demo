# AI 讲道短视频助手 V1.0｜临时演示（免费版）

- **这是一个临时演示，不是正式任务存储**：免费版没有持久盘，服务休眠或重启后，演示中的确认/废弃状态会丢失；请勿把真实讲道任务放在这里。
- **演示素材全部是合成内容**：演示视频为本地合成的测试视频（16 段通用主题），不是真实讲道；演示任务中没有任何真实讲道视频、没有任何真实成片、没有任何 Google Drive 授权信息、没有任何 API Key。
- **演示可操作**：打开网址 → 任务列表 → 播放演示视频 → 确认通过 / 修改 / 废弃；修改可重新生成（演示源视频已内置）。
- **演示不包含**：上传新视频后的云端转录与高光分析、从 Google Drive 取视频、最终字幕包装与四平台文案（这些属于正式版后续接通的功能）。
- 正式版需要持久盘与登录保护，待界面确认满意后再评估服务器配置、存储、安全措施与真实费用。

## V1.1 界面优化（2026-11-01）
- 双栏审核工作台：左侧短视频列表（含缩略图、时长、状态），右侧 9:16 播放器与三个审核按钮。
- 普通界面只显示标题、时长、状态、播放器与审核操作；评分、词数、文件指纹、音量、黑屏等技术参数收进“详细信息”。
- 顶部五步导航标出当前步骤；审核统计与最终制作门禁（未全部审核时按钮禁用）。
- 审核流程与数据格式不变，后端与 AutoClip 剪辑逻辑未动；仍为临时演示，免费版数据不保存。
